# ブロック生成

## 仕様

### 入出力

以下の引数を与えられる

* row
* column
* dictionary(単語辞書)
* requestedCount(期待単語数)
* attemptsPerWord(試行回数)
* prefetching=1(先読み回数)

文字が格納された二次元配列を返す

### 内部仕様

dictionaryの単語を使って、ランダムに選んだ最大requestedCount個の単語をグリッドに配置する。
配置は一直線である必要はなく、曲がってもよい。

配置は以下のように行う。
- 空いている座標をランダムに選ぶ
- ランダムに選んだ座標をスタート地点として、ランダムな単語を置く。

置く際には以下のルールに従う。
- 前の文字から下左右の隣接するランダムな空き場所に次の文字を置く(上には移動しない)
- 置ける場所がない場合は、単語を変えてattemptsPerWordの回数だけ試行する。

- 試行が終わっても埋まっていないマスにはランダムなひらがなを格納する。

これをprefetching回繰り返す。

例えば
* row=6
* column=6
* dictionary=[...]
* requestedCount=5
* attemptsPerWord=10
* prefetching=2

の場合、
6x12のグリッドが作られる。
前半の6x6のエリアには最大5個の単語が含まれる
